# 统一黑盒需求

## 产品与用户操作

一个Chrome MV3插件，配置一个后端HTTP/HTTPS服务器地址。无需第二插件、手填扩展ID/令牌/项目。后台统一接收、分类存储、提取并结合Agent；白盒独立仓库，不参与浏览器任务生命周期。

启动后端→插件填写IP/端口→创建统一任务→正常登录和操作→分类增量上传→查看接收/分析/模型状态→查看分来源结果与缺口→导出。

## 必须收集与保留

API实测的URL/Method、Query/Path/Body/Header、状态、可得响应与发送栈；JS正文及表示/URL/观察身份；页面/frame/target/session/导航/执行上下文；JS加载/重定向/initiator及可得同步异步栈；任务配置、预算、中断与未确认项。遵循用户字段选择，缺失原因可见。

采集所有窗口HTTP/HTTPS网页及新页/导航，跳过内部页；不自动点击、提交、刷新或重放API。浏览器不能回取的历史正文不假装完整。首版未加载脚本静态补抓仍按原显式范围/预算单独验收。

## 后端交付

1. 原始事件和正文校验、服务端哈希去重、独立观察、持久确认。
2. 固定批次和上下文归一化、引用图、静态API/参数提取、实测关联。
3. Agent针对缺口调受限工具并提供可核验建议；无模型时确定性流程可用。
4. 分来源的API主表、参数、JS与代码依据、缺口；JSON为底稿，CSV已有，Excel待实现。
5. 查询/导出和版本可回查，模型错误不污染事实，ACK不等于分析完成。

## 运行与边界

远端JS/请求内容仅在有界内存待传，持久ACK后释放，不新增浏览器正文库；离线/溢出/退出未确认登记缺口。保留旧任务和本地请求导出/SLS兼容，不静默改写旧模式。

不执行下载JS、不调用提取API、不默认向未配置模型服务发送真实代码或业务正文。固定code为联调约定，不是秘密凭证。真实服务器、模型提供方和数据可发送范围须由配置明确。
