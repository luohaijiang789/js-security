## 本轮修复：未知配置不等于空参数

之前 $http(opt) 或 axios(runtimeConfig) 在完整配置未知时，未解析出的 Query/Body/Header 会落为 null，表格显示“无显式字段”。现在这些载体显示带原因的未知值，parameterFields 保留对应载体根路径 unknown-value；不会补造字段名。

已知配置没有载体仍为 null。未知配置展开之后显式指定的 body、headers:null 等覆盖继续保留，其他未确定的载体保持未知；未知配置缺口不会被抹掉。构造字段、编码后字段和 hook 后阶段仍分开。

OSS 中 Host、URL、method 和三个载体仍未知；opt.headers 和 Global.endpoint 的修改不因发现赋值就被冒充为已恢复的最终配置。STS/RAM endpoint 只放人工发现说明。
