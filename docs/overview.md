# 当前产品总览

后端是根目录主工程，唯一插件browser-extension/。完整使用见[根README](../README.md)，当前架构见[architecture](architecture.md)。

分类为API实测、JS正文、页面/执行上下文、JS加载、任务/缺口。插件临时持久化未确认内容，ACK后清理，重启先补传；服务器核对序号/分类/字节/对象后封账。自动作业按固定水位导出种子，默认递归5层、冻结后统一提取，插件查询API/参数/JS证据和Gap。

JS按每个解析观察读源，服务器按内容去重；同URL不等于同版本。原始观察、静态候选、模型建议分别计数。直接调用可核验AST发送位置，动态封装/跨层实例仍是候选；Agent已有默认关闭的手动工具循环入口，真实模型及Excel仍待验收/实现。

legacy、独立旧插件、旧探索导入和/v0服务已删除；白盒不在本仓继续建设。

原始日志覆盖现有12类CDP通知及四类证据读取命令的发起/结果，先持久后原子移交，重启补传与原始账目封账见[capture-journal](capture-journal.md)。后端可恢复缺少整理记录的请求和已保存的源码/正文/父栈，按原始身份去重；完整原文按需查询和导出，未返回/未持久结果与解析预算明确留缺口。
