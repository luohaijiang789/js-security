# 当前端到端流程

1. 唯一插件使用同一CDP会话收集API、JS、上下文、加载证据和任务状态。
2. 已接纳事件先进入严格事务的临时持久队列，携带固定上传身份和连续序号。
3. 服务端校验分块/正文、持久事件和分类账后ACK，插件原子清理正文并更新确认状态。
4. 失败暂停，重启恢复同一接收端的队列；全部未确认数据处理后才恢复新采集。
5. 后端自动合并持久事件，按水位导出种子，递归收集JS（默认5层）、结算冻结，再统一静态提取并保守关联实测。
6. 插件查询作业与结果，查看API/参数/JS证据、Gap，导出JSON。
7. 停止时等待在途/队列，提交检查点，由服务端核对连续序列/分类/字节/对象，成功封账后结束。

Agent未接入，仍为后续受限工具/核验设计；不存在第二个独立插件或/v0产品。技术见architecture.md，wire见protocol.md，准确性边界见analysis-design.md。
