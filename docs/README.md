## 编辑标准

| 内容 | 形式 | 验收 |
|---|---|---|
| 目的/决定 | 开头短段或决定表 | 能看懂要解决什么、交付什么 |
| 依赖/往返 | 流程图 + 关键动作 | 有真实分支和下一步 |
| 比较/分工/证据 | 表格 | 字段可比较，未确定项明确 |
| 工作任务 | Checklist | 动作、范围、证据与负责人可追踪 |
| 操作 | 动作/产物表 + 填好示例 | 能执行，反例能改变判断 |
| 调研/笔记 | 问题 → 证据/决定 → 下一步 | 不堆网站或重复会议叙事 |

同一规则只在一个当前文件维护，其他位置引用；技术分歧回原始版本证据。历史结论不因新稿而改成“已验证”。原始业务敏感证据使用受限存储，不放普通仓库。
