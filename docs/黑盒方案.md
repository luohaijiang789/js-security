# 黑盒方案

**状态：方案已确定，用户确认已验证有效。**

## 采集方式

使用浏览器插件获取阿里云美国独立站所有页面的接口、参数信息和调用栈。

| 采集结果 | 对应关系 |
|---|---|
| 页面 | 请求在哪个页面产生 |
| 接口 | 页面调用了哪些接口 |
| 参数信息 | 每个接口携带哪些参数 |
| 调用栈 | 对应请求的代码调用链 |

页面、接口、参数和调用栈关联保存，供白盒反查。

## 与白盒如何配合

- **黑盒 → 白盒**：根据实际接口、参数和调用栈，定位仓库中的发送位置、字段来源、公共封装和 SDK 注入逻辑。
- **白盒 → 黑盒**：把代码中新发现的接口、传输路径和触发条件交回黑盒，补充验证。

当前继续设计白盒如何使用这些结果；插件实现细节及导出格式尚未写入本项目。
