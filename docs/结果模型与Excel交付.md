# 结果模型与 Excel 交付

本文件集中定义三路结果的证据、记录粒度及交付语义。当前为设计约定，具体机器字段名和 Schema 需在样例验证后定版。

## 1. 三类证据与记录粒度

| 来源 | 一条基础记录代表什么 | 必须保留的来源依据 |
|---|---|---|
| 仓库静态 | 指定配置和分支条件下的一个请求调用上下文 | 仓库、Commit、文件行列、调用点和可定位发送点 |
| 网站 JS 静态 | 指定部署脚本与上下文中的一个请求调用候选 | 脚本 URL/哈希、页面、引用链、代码位置 |
| 插件实测 | 一次实际观测的请求；重定向按跳次区分 | 任务/请求 ID、时间、页面/场景、target/会话及采集状态 |

API 总表保留以上基础记录；插件请求组、API 组属于关联视图，不能替代原始记录。WebSocket 增强采集时，连接与消息分开并建立关联。

证据来源与发现依据分别保存：静态定位到发送点、未确认封装调用、仅 URL 字符串命中不能混为同一确定程度。后两者明确标记为待确认候选，不计入已定位发送行为。

同 URL/Method 仅提供 API 组候选。跨来源关联还应核对版本、调用位置、配置和场景，保存“未核对/候选关联/证据支持”的状态与依据；不能因此覆盖原记录或把错版代码视为同版。

## 2. 工作簿 api_assets.xlsx

### API 总表

支持按 Host、Path、Method、来源、候选状态和完整性筛选；保留不同调用与观察记录。

| 列组 | 内容 |
|---|---|
| 身份 | 记录 ID、任务 ID、候选 API 组 ID、来源、发现依据/候选状态 |
| 目标 | Host、完整 URL 或表达式、Path、Method、发送机制/资源类型 |
| 参数摘要 | 路径变量、Query、Header、Body/消息字段，关联参数明细 |
| 质量 | 地址解析状态、各载体结构状态或采集状态、缺失原因及缺口 ID |
| 静态定位 | 仓库/Commit、文件行列、业务调用点、发送点、条件及适用配置 |
| JS 资产 | 脚本 URL、内容哈希、来源、引用链与获取深度 |
| 实测上下文 | 页面、场景、时间、请求 ID、target/会话、重定向跳次、请求状态 |
| 证据关联 | 证据 ID、版本关联状态、模型/Schema 版本、关联记录 ID |

某来源不适用的列标“不适用”，应有却无法取得的列标“未知/缺失”并写原因。Host 是输出属性，不用于排除请求；端口和协议在完整 URL 中保留。未知 Method 不统一默认 GET；WebSocket 消息的 HTTP Method 不适用。

### 参数明细

一行对应某记录中的一个字段，包含记录 ID、载体、嵌套字段路径、值表达式或脱敏观察、构造/改写位置、阶段、条件和状态。构造阶段字段与最终候选载荷字段明确区分。保留数组结构、重复键和顺序语义。

未展开对象/spread 单独记录表达式和影响，不伪装成真实网络字段。不同调用的字段即使归入同 API 组，也保留所属记录及出现条件。

### 分析缺口

一行对应一处未解决问题：缺口 ID、关联资产/请求、类型、位置、原因、影响和后续动作。包括运行时配置/外部实现不可见、超深度、解析失败、未知调用/对象、可能覆盖/删除、预算耗尽及采集中断。

缺口可以只关联资产而没有请求 ID，因为未取得的代码可能包含尚未发现的 API。

## 3. 状态不能混用

| 维度 | 状态与含义 |
|---|---|
| 静态地址解析 | 已解析 / 部分解析 / 未知，保留具体已知部分和条件 |
| 静态各载体结构 | `COMPLETE_WITHIN_MODEL` / `PARTIAL` / `UNKNOWN`；不适用另记 |
| 实测采集状态 | 各载体及调用栈分别记录完整 / 部分 / 缺失 / 不支持 / 不可解析；附原因 |
| 值的保护 | 单独记录脱敏、删除或截断，不把脱敏字段当不存在 |

`COMPLETE_WITHIN_MODEL` 只表示已追踪路径及受支持模型内结构已解析，必须附分析范围和模型版本；不证明所有运行时行为已覆盖。已知存在未建模改写时不可标完整。

“确认无显式字段”“未知”“未采集”“不适用”分别表达。字段值动态不自动降低结构状态；Host 未知也不必使已知 Query 结构变未知。一次实测完整不提升其他调用或静态路径的完整性。

## 4. 文件与追溯

- `api_assets.xlsx`：人工查看与筛选；三个 Sheet 使用记录/缺口/证据 ID 关联。
- `analysis.json`：机器可读底稿，保存资产、配置可用性、模型版本、表达式、代码依据、缺口和跨来源关联。
- 插件原始 JSONL 包：按[插件规格](JS%20请求采集浏览器插件.md)保留；导入时在底稿记录包/分片、请求 ID 和定位信息，确保可回查。

Excel 不放敏感原值或超长源码，外部字符串按文本写入。长内容通过证据 ID 关联，不静默截断；超过工作表行数上限时按来源/分片拆分并提供清单，不丢弃记录。敏感值保护不破坏字段名、结构和缺失标记。

三路分别记录运行/任务标识、工具与 Schema 版本、时间、范围、配置及错误统计。未知版本保留未知，不以同名文件代替内容版本。没有真实输入时不生成伪造扫描结果。
