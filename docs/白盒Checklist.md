# 第一阶段 M1～M5 Checklist

范围已冻结为前端 API 与请求参数提取。以下是待开发、待验证项；当前没有实测覆盖率。

## 准备材料

- [ ] 一个试点仓及固定 Commit；不要求目标 Host。
- [ ] 可用配置、模块别名、锁文件、组件/构建方式及主要 SDK 版本。
- [ ] 外部 JS 的允许来源与可用实现；获取深度默认 3。
- [ ] 可选黑盒请求、参数与调用栈，用于对照；缺失不阻断扫描。
- [ ] 人工标注的请求/字段样本及反例；确定 AI 允许读取和发送的代码范围。

## 按模块开发

### M1 JS 资产解析

- [ ] 识别 JS/TS、组件与 HTML 脚本，解析静态引用和可确定动态加载。
- [ ] 解析本地模块、依赖入口与别名；声明文件不能代替实现。
- [ ] 外部 JS 获取后继续执行 M2～M5；循环去重、深度截断、失败原因可追溯。

### M2 请求行为发现

- [ ] 支持 fetch、Axios、XHR、Beacon；XHR 的 open/header/send 关联同一实例。
- [ ] 常见 request 封装可连接发送实现，函数同名不直接认定请求。
- [ ] SDK 自动请求参与发现；WebSocket、Pixel、Form 按机制记录。
- [ ] 未确认调用与已识别请求分开，Host 不参与排除。

### M3 API 提取

- [ ] 提取 URL/表达式、Path、Method；支持配置、拼接、baseURL 与静态可解析跨文件调用。
- [ ] 隔离 client、调用者与分支条件；默认 Method 来自机制模型。
- [ ] 相对地址缺基址仍输出；未知最终地址保留改写位置与原因。

### M4 参数提取

- [ ] 提取各载体、嵌套与数组字段，以及值表达式。
- [ ] report(data) 能跨文件连接调用方对象，不停留在变量名 data。
- [ ] 已知 spread/合并可展开；未知 spread 保留缺口及可能覆盖的字段。
- [ ] 处理确定实例上可解析的默认字段、拦截器注入/删除和常见序列化。
- [ ] SDK 可见字段提取，不透明逻辑和复杂动态传播明确返回 PARTIAL/UNKNOWN。

### M5 结果汇总

- [ ] Excel 总表、参数明细、缺口表与关联 JSON 可回查仓库、版本、文件行列、调用和发送位置。
- [ ] API 归并保留各调用的字段差异与条件，不把并集当每次发送内容。
- [ ] 地址状态与各载体结构状态分开；无字段、未知字段和未解析请求不混淆。
- [ ] 资产获取/解析缺口单独输出，不因尚未发现请求而隐藏。

## 核心比较题

| 样例 | 必须观察的结果 |
|---|---|
| 直接发送与同名非网络函数 | 提出请求，排除名称误报 |
| 跨文件 report(data) → request.post | 提出调用方字段及调用链，不混不同调用者 |
| 多个 client 与 baseURL | 地址、参数、拦截器属于正确实例 |
| 未知 baseURL + 已知路径和字段 | 保留请求与字段，地址单独标未知 |
| 已知字段后接未知 spread | 保留字段但注明可能覆盖；未知 spread 不冒充真实字段名 |
| 拦截器追加/删除、JSON 过滤 | 区分构造过的字段和最终候选字段 |
| 别名写入、浅拷贝、嵌套共享 | 可处理的正确连接；未支持副作用标部分，不假完整 |
| 外部 SDK、缺实现、循环引用 | 已取得实现同等分析；断点和受影响调用有记录 |
| 动态回调、队列、自定义编码 | 允许未知，不生成虚假的确定结构 |
| WebSocket、Pixel、Form | 机制和载体正确，不强行转成 JSON POST |

## 选型与验收

- [ ] 用同一批样例比较 AST/有限追踪、Grep+AI、CodeQL；优先验证跨文件请求链，再决定最小实现组合。
- [ ] 公共封装模型用未参与建模的新样例复验；AI 提议模型须有代码位置和正反例。
- [ ] 分析预算与 JS 获取深度独立；超时/节点耗尽记录中断位置。
- [ ] 对照已有黑盒样本，保留版本不明、调用多候选及字段差异。

| 验收指标 | 统计边界 |
|---|---|
| 请求召回与误报 | 人工标注样本中的请求上下文；未确认候选单列 |
| 参数准确性 | 调用 + 载体 + 字段路径；统计漏字段、误字段与错误合并 |
| 完整性标记 | 特别检查含未知依赖/改写的结果是否误标完整 |
| JS 分析范围 | 已发现文件的获取/解析情况；不冒充全部运行 JS |
| 成本 | 执行时间、模型适配量、AI 调用与人工复核量 |

当前全部未测。发布指标须附分母、支持机制和遗留点；不外推全站覆盖率。

主设计见[白盒方案](白盒方案.md)，详细研究见[Temp](../Temp/README.md)。

## 三入口与最终交付

- [ ] Host 为独立输出列；相对 URL 缺基址时标未知，不进行 Host 筛选。
- [ ] 网站 JS 收集与源码扫描复用请求提取模型；已采集脚本及嵌套链可核对。
- [ ] 插件实测、网站 JS 静态、仓库静态分别标记，错版不强并。
- [ ] Excel 可筛选、定位字段明细；长证据通过 ID 关联，不静默截断；外部字符串按文本写入。
