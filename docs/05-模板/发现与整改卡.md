# 发现与整改卡模板

## 身份与主张

| 字段 | 填写 |
|---|---|
| 案件/发现/路径/观察 ID | 待填 |
| 应用/commit/脚本/配置/环境/时间 | 待填 |
| 一句话主张 | 哪字段在什么条件下经什么载体进入哪里 |
| 负责人/复核人 | 工程、业务、下游、隐私/法务分别指定 |
| 影响范围 | 调用者/页面/接口及差异明细 |

`来源 → 变换 → 序列化/载体 → 发送 → 接收/下游 → 访问主体`

| 主张 | 证据引用与版本 | 状态/反证/待办 |
|---|---|---|
| 字段来源与变换 | 待填 | 待填 |
| 条件与源码发送能力 | 待填 | 待填 |
| 场景实际发送 | 待填 | 待填 |
| 下游处理/留存 | 待填 | 待填 |
| 主体/区域/有效访问 | 待填 | 待填 |
| 用途与 EO 适用 | 待填 | 待填 |

- [ ] 对象/属性、联合条件、时间、序列化、运行归属检查支持路径。
- [ ] 代码/配置/观察相容；未知与不成立分开。
- [ ] 已查反例与结论失效条件：待填。

## 修改与验收

| 要求 | 填写 |
|---|---|
| 真实修改点 | 文件/符号/配置/后端/权限位置 |
| 允许行为与差异 | 哪些字段/接口保留，依据来自谁 |
| 主路径与旁路 | 错误、重试、旧队列、备用发送、重注入 |
| 业务影响与失败策略 | 负责人及回归场景，回退约束 |
| 历史/下游处置 | 日志、复制/备份、供应商副本及限制 |
| 复验规格 | 条件/动作/预期/反例/所需观察与下游证据 |
| 结果与剩余项 | 双侧、业务、下游及适用复核，未结项负责人 |

技术问题、业务必要性、法律判断分别由责任人确认。逐阶段关闭要求见[Checklist R/V/F](../../deliverables/项目Checklist.md)；示例见[白盒操作稿第 4 节](../../deliverables/白盒怎么做.md)。
