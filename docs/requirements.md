# 黑盒产品需求

后端根目录独立启动，一个生产插件只填服务器地址。收集API请求/响应、JS正文、页面/执行上下文、加载请求/栈、任务配置/缺口，后端分类存储、核对、自动提取和回传。

本轮用户已授权临时持久化未确认内容；ACK后原子清理，恢复先补传再接入页面。未确认不得静默丢弃、删除或称完成。JS去重以服务器正文身份为依据，不能用同URL跳过新版本。

用户正常操作浏览器，工具不自动点击、执行脚本或重放业务API。所有窗口HTTP/HTTPS网页/新页自动接入；权限、预算、暂停和浏览器未提供正文有明确Gap。传输确认与捕获完整性分开。

插件展示分类接收/待传/封账、作业状态、API清单、参数/JS证据和缺口，支持JSON。静态仍为文件级候选；Agent、精确绑定和Excel未完成。实际配置/运行见根README，实际协议见protocol.md，唯一状态见plan.md。
