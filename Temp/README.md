## 目前最重要的三个判断

1. **先确定运行代码的边界。** 仓库、依赖、构建产物和远程脚本可能不一致；缺失代码必须显式留账。
2. **调用关系不等于字段流。** 找到请求函数后，还要查对象、字段、注入、覆盖、序列化与发送条件。
3. **黑盒是有效的既有输入。** 用接口/参数/调用栈反查；白盒也独立发现，再返回新路径供黑盒验证。
