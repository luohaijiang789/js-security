# Baxia 公开脚本样本

项目用途：复核前端 JS 注入/直传的静态能力，帮助设计黑白盒特征与场景。原始脚本/响应头保持原样；它们不是业务实测或跨境违规证据。

此目录保存 2026-10-15 从公开 CDN 获取的五个 JavaScript 响应及对应 HTTP 响应头，仅供 [静态核查](../../docs/03-案例/Baxia/公开SDK静态核查.md) 的证据复核。原始 URL、版本和 SHA-256 见核查文档。样本为第三方作品，权利归原权利人；本仓库不对其授予使用许可，也不建议将其接入生产环境。

`.headers` 文件记录的是公开脚本响应，不含业务请求或用户数据。脚本未在本项目中执行。后续 CDN 响应可能变化，复核时应比对文档中的 SHA-256。
