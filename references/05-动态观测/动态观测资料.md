# 动态观测：能看什么，还缺什么

| 能力/来源 | 用在本项目哪里 | 待核条件 |
|---|---|---|
| [CDP](https://chromedevtools.github.io/devtools-protocol/) | 资源/请求/脚本/上下文与发起线索 | 固定浏览器/协议版本、target 与载体；网络事件不等于落库 |
| [Playwright](https://playwright.dev/docs/intro) | 独立旅程与白盒定向场景 | 角色、异常、队列/采样；未执行状态另记 |
| [OpenWPM](https://github.com/openwpm/OpenWPM) | 请求/JS 访问结构、场景身份与失败记录 | 字段开关与有效值、目标站兼容；已核片段未运行 |
| [Tracker Radar Collector](https://github.com/duckduckgo/tracker-radar-collector) | 模块化收集与发起链 | 默认请求结果缺头/body；本方 API 不能过滤掉 |
| [Foxhound](https://github.com/SAP/project-foxhound) | 特定来源到 sink 动态血缘 | 实际构建 source/sink、对象/二进制/异步范围 |
| [mitmproxy](https://docs.mitmproxy.org/stable/) | 代理记录/受控对照的补充 | 协议/TLS、业务兼容及干预，不能替代 JS 字段来源 |

本轮固定源码与待实验见[GitHub 核查](../06-开源项目/GitHub方案核查.md)，详细执行见[黑盒操作稿](../../deliverables/黑盒怎么做.md)。

- [ ] 正例确认观察工作；未触发、失败、不可观察和有界未见分开。
