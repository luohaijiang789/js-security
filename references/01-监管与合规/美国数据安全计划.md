# EO/DSP：技术调查必须补齐哪些事实

目的：给前端 JS 跨境透传的适用复核提供事实。技术团队取证，隐私/法务确认规则解释、适用与处置；任务编号统一见[Checklist E01～E09](../../deliverables/项目Checklist.md)。

| 待确认事实 | 技术/业务材料 | 官方复核入口 |
|---|---|---|
| 数据类型、数量、组合与时间口径 | 字段来源/变换、对象去重与业务数据规模；不是请求条数 | [28 CFR Part 202](https://www.ecfr.gov/current/title-28/chapter-I/part-202) |
| 主体、交易、例外/授权 | 交易/合同、提供与接收主体、组织/人员关系 | 同上及 [DOJ DSP](https://www.justice.gov/nsd/data-security) |
| 真实传输、最终用途和访问 | 双侧路径、API/日志/存储、有效权限、供应商材料 | [Compliance Guide](https://www.justice.gov/opa/media/1396356) |
| 适用受限交易的控制 | 组织、系统、数据与密钥/访问证据 | [CISA Security Requirements](https://www.cisa.gov/resources-tools/resources/EO-14117-security-requirements) |
| 当前修订、指南与义务 | 责任团队确认版本及适用条件 | [DOJ 当前资源入口](https://www.justice.gov/nsd/data-security)、[最终规则发布](https://www.federalregister.gov/documents/2025/01/08/2024-31486/preventing-access-to-us-sensitive-personal-data-and-government-related-data-by-countries-of-concern) |

## 案件记录要求

- [ ] 区分美国相关数据、站点部署地、首跳、处理/留存区域、法律主体和有效访问。
- [ ] token、加密、美国落地或域名后缀均不单独关闭问题；核关联/密钥和下游。
- [ ] 把技术主张、供应商声明和法务判断分别引用，未知事实有负责人。
- [ ] 按适用条件安排控制、尽调、审计/记录等义务，前端扫描不冒充全部合规工作。
- [ ] 正式结案前由责任团队核当前规则与指南，保留范围与剩余任务。

核验记录：2026-10-20 读取 DOJ DSP 与 eCFR；CISA 页面返回 403，保留 DOJ 所列官方入口，本轮未重读其正式正文。此前已整理的资料不表示当前逐条法律审查。没有对真实站点作适用或违规认定。
