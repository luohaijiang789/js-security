# 需求与用户操作

## 1. 产品形态

黑盒二是黑盒一的远端数据处理与静态分析后端，统一生产插件为 `browser-extension/`。插件采集真实请求、JS与加载证据并上传，后端保存原始证据、去重正文、关联来源并持续跨文件分析。当前运行范围见[原型调试说明](plugin.md)，状态只见[计划](plan.md)。

直接增强现有黑盒一，不再先交付第二个完整插件。复用网络/调用栈采集、目标会话、任务、存储和界面；现有独立采集原型只作迁移和测试参考。已实现统一插件与独立v1接收闭环；未删除旧原型，也未部署实际远端。CLI仍为核心调试入口，已删除旧后端不作为兼容实现。

## 2. 目标用户流程

以下包含后续补抓、精确分析和Excel目标，不是当前原型已全部支持的操作。生产插件按钮和配置见[黑盒一使用说明](../../browser-extension/docs/usage.md#远端采集js和请求内容不落浏览器本地盘)，旧独立原型另见plugin.md。

1. 填写接收服务HTTP/HTTPS地址（固定code内置，不需扩展ID/手动令牌），点击黑盒一插件图标打开管理标签页；采集内容只经有界内存直传，不写浏览器本地盘；远端失败或队列满时暂停并记录缺口，退出后未确认内存数据不可恢复。
2. 创建任务，确认目标服务，设置静态资源补抓允许范围和缓存/上传预算。新任务自动接入当前浏览器所有窗口中的 HTTP/HTTPS 网页及后续新网页，不要求选择标签页。
3. 点击开始，插件先读取可取得的当前页面/脚本，再持续收集新加载脚本。用户按正常方式登录和操作业务；不自动点击、提交表单或刷新页面。
4. 新正文/加载记录持续上传并触发解析，工作台更新已取得/已确认上传/已解析/待补全数量、接口候选、引用图及缺口。初次附加前已丢失的正文、未知父链或失败页面立即显示。
5. 远端自动按已提交事件水位形成不可变分析批次；单文件结果先输出，依赖到达后修订相关结果。快照保存引用清单，采集不因生成批次而暂停。用户可导出某个固定版本复核。
6. 查看 API 主表及右侧详情，分别检查地址、参数、JS 位置、引用/调用链、改写阶段和缺口；可以补充操作后生成新快照对照。
7. 停止收集，等待有界排空并导出 `api_assets.xlsx`、`analysis.json` 和可复核资产包；超时的在途资产保留缺口。

首版不自动遍历站点页面。前端路由/manifest 用来发现可静态确定的脚本，不以访问所有路由作为获得 JS 的前提。页面自动遍历属于后续单独设计范围。

## 3. 正式交付目标

| 项目 | 要求 |
| --- | --- |
| 四项结果 | URL、Query/Path/Body/Header 参数结构、Host、最终发送所在 JS；方法和证据为辅助 |
| 分层范围 | 覆盖直接请求、依赖自发、多层调用和请求加工；语义见[共享范围](../../docs/js-analysis-scope.md) |
| 脚本来源 | 浏览器可取得脚本、静态引用补抓、source map 辅助分别记录 |
| 获取深度 | 页面内联 D0、直接外链 D1、继续引用 D2/D3；更深引用留账；不限制已有脚本内部函数为三层 |
| 结果状态 | 各字段分别为 confirmed/partial/candidate/unknown；空结果与未完成分析区分 |
| 可追溯 | 正文与观察分离；每次加载的请求/重定向、页面/目标/导航/执行上下文、来源类型、可得同步/异步调用栈、静态引用与缺口可回查 |
| 独立运行 | 不依赖黑盒一采集结果或白盒构建；后续白盒可接入同一分析协议 |

用户结果过滤只改变展示或导出视图，不裁剪分析依赖。静态补抓来源范围与结果 Host 分开：不按 API Host 删除发现；第三方 SDK 和埋点与业务代码同样分析。

## 4. 边界

- 不主动调用提取出的 API，不自动重放请求，不执行下载 JS，不通过运行任意代码来求值。
- 远端可接收黑盒一的真实请求信息并存储/查询；这些仍标实测来源，不与JS推导候选混算次数或确认为同版接口。
- 不承诺从一次页面加载取得全站 JS。未加载且无法静态枚举的代码、运行时配置和复杂副作用记录缺口。
- 远端接收用户明确选择服务/项目范围内的完整 JS 和加载证据，地址可预置但可配置，认证凭证不写死进插件。JS加载请求元信息与业务API实测分开；实际请求上传字段遵从黑盒一现有采集/上传选择，JS分析不能暗中扩大范围，控制面配对凭证不混入业务证据。原始代码不默认发送给AI。
- AI 为后续可选增强，只提出经 AST/绑定核验的结构建议；无 AI 时主流程可完成。
- 现有独立原型仅供迁移验证，生产能力直接进入黑盒一；改造时统一 CDP 会话所有权与事件分发，黑盒一/DevTools 的连接干扰不得以静默抢占处理。

阶段交付与门槛见[实施计划](plan.md)及[测试与验收](testing.md)。
